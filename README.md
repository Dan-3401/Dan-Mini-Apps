# Dan Mini Apps

Five small desktop and browser tools made by Dan.

五个由 Dan 制作的小工具。  
Dan が制作した 5 つのミニアプリです。

## Apps

| App | Description | Launch |
| --- | --- | --- |
| Rhythm Studio | Transparent audio-reactive overlay creator | `rhythm-studio/launch.cmd` |
| Bilibili Downloader | Local Bilibili video downloader for content you have permission to save | `bilibili-downloader/start.bat` |
| QuickClip | Fast local audio and video clipper for RVC workflows | `quickclip/启动 QuickClip.bat` |
| Paper Stock Simulator | Local browser-based paper trading simulator | `paper-stock-simulator/index.html` |
| Topmost Keeper | Keep selected Windows apps permanently on top | [Download Windows x64](https://github.com/Dan-0721/Dan-Mini-Apps/releases/download/topmost-keeper-v1.0.0/TopmostKeeper-win-x64.zip) |

Each app includes a visible Dan credit and Chinese, Japanese, and English interface support.

每个应用均已标注 Dan 制作，并加入中文、日文、英文界面。  
各アプリには Dan のクレジットと、中国語、日本語、英語の UI が含まれています。

## Notes

- The Bilibili downloader installs its Python dependencies into a local `vendor/` folder on first use.
- QuickClip requires `ffmpeg.exe` and `ffprobe.exe` in `quickclip/bin/`, on `PATH`, or in `D:\Codex\RVC1006Nvidia`.
- Topmost Keeper is a Windows x64 app. Its source and local build script are in `topmost-keeper/`.
- Use the tools only for content you have permission to save and process.
